# MemeScope V19.3 — Direct Launch Stream

- Nuevo stream WebSocket en el navegador para recibir nuevas creaciones Pump.fun en tiempo real.
- Los tokens aparecen inmediatamente, sin esperar indexación de DexScreener.
- Se conservan solo 5 minutos en la vista instantánea.
- Cada token nuevo incluye mint y accesos directos a Pump.fun, Jupiter y Solscan.
- DexScreener queda como segunda capa de enriquecimiento para precio, trades, volumen, liquidez y seguridad.
- Estado visible del stream: CONECTANDO / LIVE / OFFLINE.
- La vista advierte explícitamente que recién creado no significa buena compra.
